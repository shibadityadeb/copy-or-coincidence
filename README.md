# copy-or-coincidence

**Excess error correlation in multi-agent LLMs.** When two agents give the same wrong answer, did one copy the other, or would it have happened anyway?


Measures how much of two agents' shared wrong answers is predictable from each agent's own
per-question behaviour (item-conditioned null), and how much is caused by interaction.
Plan: `Excess_Error_Correlation_Field_Guide_1.pdf`; plain-language overview: `project-explainer.html`.

## Setup

```bash
uv venv --python 3.11 .venv && uv pip install --python .venv/bin/python -e .
.venv/bin/python -m pytest          # checker + generator tests
.venv/bin/python -m cep.build       # rebuilds datasets/cep_v1 (byte-identical for seed 0)
```

## Item set: `datasets/cep_v1` (300 items, frozen)

| Family | Source | n | Lure | Error cause |
|---|---|---|---|---|
| lure | 10 trick-question templates, fresh numbers (`cep/generators/crt.py`) | 100 | intuitive answer | `intuitive_lure` |
| logic | ProntoQA, fictional words (`renma/ProntoQA`) | 50 | none | `deduction_slip` |
| logic | false-world rules (`cep/generators/false_ontology.py`) | 50 | common-sense answer | `prior_override` |
| math | GSM-Plus missing premise (`qintongli/GSM-Plus`) | 50 | original problem's answer | `missing_premise` |
| math | GSM-Plus inserted distractor | 50 | none | `distractor` |

`manifest.json` records the items hash, dataset revisions, and the checker version.
`audit_sample.md` lists 30 items to check by hand.

## Grading

`cep/parse.py` reads the model's JSON reply → `cep/normalize.py` turns the answer into a canonical
string → `cep/checker.py` labels it `correct / lure / unanswerable_answered / false_unanswerable /
other_wrong / format_error`. No LLM judge is used. `CHECKER_VERSION` is a hash of those three files
and goes on every result row.

## Kaggle
